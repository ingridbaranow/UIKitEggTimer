# Egg Timer

## The Goal

This project is a combination of tutorials and personal challenges. Most importantly, my goal was to get more comfortable with figuring out how to do things I've never done before. In some parts of this project, I followed the 5-step process that I learned in the Xylophone module and relied on Google search, StackOverflow, and Apple Documentation to make my code work the way I wanted. In other areas, I explored new Swift programming concepts step by step.

## What I Built

I created a beautiful egg timer app that helps boil eggs to perfection, depending on how you like them.

## What I learned

* Swift Collection types - Dictionaries
* The Swift Timer API
* Conditional statements - IF/ELSE
* Conditional statements - Switch
* Functions with outputs
* How to use the ProgressView
